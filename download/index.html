安装

01

解压下载的压缩包

双击 MCOM-1.0.zip，会得到一个 MCOM.app。

02

拖进「应用程序」文件夹

从任何位置运行也可以，但放进 /Applications 之后才能被 Spotlight 找到、被程序坞固定。

03

第一次打开：右键 → 打开

MCOM 没有经过 Apple 公证（个人开发者，一年 99 美元的开发者账号还没买）。直接双击会被 Gatekeeper 拦下， 提示「无法验证开发者」。这不是病毒警告，是「我没见过它」。

方法一：在 Finder 里按住 Control 点按 MCOM，选「打开」，再确认一次。之后就能正常双击了。

方法二：在「终端」里跑一行命令，去掉下载隔离标记：

xattr -dr com.apple.quarantine /Applications/MCOM.app
为什么会被拦？ macOS 对从网络下载的、没有 Apple 公证的应用一律提示「无法验证开发者」。MCOM 使用 ad-hoc 签名并开启了 Hardened Runtime，代码是完整的、没有被篡改 —— 只是没有向 Apple 购买那张证书。上面两种方式都能正常打开。

先装个 Java

MCOM 不捆绑 Java，用的是你系统里已经有的一份。所以第一次打开之前，先确认有没有。 在「终端」里跑这一行：

/usr/libexec/java_home -V

列出一串版本号（17、21 之类）就说明有，直接跳到下一节。如果提示 Unable to find any JVM，那就是真没装，接着往下看。

去 Oracle 下

下载页在这：oracle.com/java/technologies/downloads。 找到 JDK 21 那一栏，按自己的芯片选 DMG：

Apple Silicon macOS ARM64 DMG Installer
jdk-21_…_macos-aarch64_bin.dmg
Intel macOS x64 DMG Installer
jdk-21_…_macos-x64_bin.dmg

双击 dmg，一路下一步。装完不用配 JAVA_HOME，也不用改 PATH —— MCOM 自己去 /Library/Java/JavaVirtualMachines 底下数。

Oracle 现在得登录账号才能下。 嫌麻烦的话用 Adoptium 的 Temurin，同一套 OpenJDK 的免费构建，下载不要账号： adoptium.net。 装哪个 MCOM 都认。

哪个版本要哪个 Java

1.20.5 及以后Java 21
1.18 – 1.20.4Java 17
1.17Java 16
1.16.5 及更早Java 8

只玩新版的话，装一个 JDK 21 就够。想开 1.16 或更早，还得再装个 JDK 8 —— Oracle 页面往下拉能翻到，注意它的包名是 macosx 不是 macos。 几个版本同时装着不会打架，MCOM 会按实例挑。

Java 有了，剩下三步

01

新建实例

点侧栏的「+」，选一个游戏版本。列表里有 900 多个版本，输入 1.21.1 就能直接定位。

02

等它下载完

客户端、依赖库、资源文件会并行下载，进度、速度、剩余时间都在下载面板里。中断了也没关系，已下载的部分会留着。

03

点「启动游戏」

启动前会自检 Java、依赖库、资源索引。全绿就直接进游戏；有问题会明确告诉你是哪个。

账户：目前只支持离线账户 —— 起个名字就能玩单人模式和局域网。微软正版登录的数据结构与钥匙串通道已经写好，界面还没做， 这一版先不发。如果你只玩单机与自建服务器，离线账户足够了。

这一版还没有的东西

微软账户登录数据结构与 Keychain 通道已就位，UI 未做
自动更新新版本需要手动下载覆盖。应用本身不联网检查更新
整合包导入导入 / 导出逻辑已写，还没有入口
Forge / NeoForge通过官方 installer 安装，需要本机有可用的 Java
Apple 公证没有。首次打开需要右键，见上方安装步骤
