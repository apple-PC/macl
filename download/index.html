导入即装导入整合包后，若本机尚未安装对应的游戏版本，Macl 将自动补齐客户端、依赖库与资源文件，无需待至启动时方才报错。进度实时呈现在导入进度条中

安装

01

解压下载的压缩包

双击 Macl-1.3.2.zip，会得到一个 Macl.app。

02

拖进「应用程序」文件夹

从任何位置运行也可以，但放进 /Applications 之后才能被 Spotlight 找到、被程序坞固定。

03

第一次打开：右键 → 打开

Macl 尚未通过 Apple 公证（个人开发者，每年 99 美元的开发者账号尚未购买）。直接双击会被 Gatekeeper 拦截， 提示「无法验证开发者」。此提示并非病毒警告，而是系统对未登记应用的常规提醒。

方法一：在 Finder 里按住 Control 点按 Macl，选「打开」，再确认一次。之后就能正常双击了。

方法二：在「终端」里跑一行命令，去掉下载隔离标记：

xattr -dr com.apple.quarantine /Applications/Macl.app
为何会被拦截？ macOS 对自网络下载、且未经 Apple 公证的应用一律提示「无法验证开发者」。Macl 采用 ad-hoc 签名并启用了 Hardened Runtime，代码完整、未经篡改——仅缺少向 Apple 购买的证书。以上两种方式均可正常打开。

先安装 Java 运行时

Macl 不捆绑 Java，使用系统中已有的运行时。因此首次打开前，请先确认是否已安装。 在「终端」中执行以下命令：

/usr/libexec/java_home -V

若列出一连串版本号（如 17、21），即表示已安装，可直接进入下一节。若提示 Unable to find any JVM，则表示尚未安装，请继续向下阅读。

前往 Oracle 下载

下载页在这：oracle.com/java/technologies/downloads。 定位至 JDK 21 一行，并依据芯片类型选择对应的 DMG 安装包：

Apple Silicon macOS ARM64 DMG Installer
jdk-21_…_macos-aarch64_bin.dmg
Intel macOS x64 DMG Installer
jdk-21_…_macos-x64_bin.dmg

双击 dmg 并按提示完成安装。安装后无需配置 JAVA_HOME，亦无需修改 PATH—— Macl 会自动检索 /Library/Java/JavaVirtualMachines 目录。

Oracle 现需登录账号方可下载。 若希望免去注册步骤，可采用 Adoptium 的 Temurin——同为 OpenJDK 的免费构建，且无需账号： adoptium.net。 无论安装哪一个，Macl 均可识别。

各版本对应的 Java 版本

1.20.5 及以后Java 21
1.18 – 1.20.4Java 17
1.17Java 16
1.16.5 及更早Java 8

若仅游玩较新版本，安装一个 JDK 21 即可。如需运行 1.16 或更早版本，则需另行安装 JDK 8—— 可在 Oracle 页面下方找到，注意其包名为 macosx 而非 macos。 多个版本同时安装不会冲突，Macl 会依据实例自动选择。

Java 就绪后，余下三步

01

新建实例

点击侧栏的「+」，选择一个游戏版本。列表包含 900 余个版本，输入 1.21.1 即可快速定位。

02

等它下载完

客户端、依赖库、资源文件会并行下载，进度、速度、剩余时间都在下载面板里。中断了也没关系，已下载的部分会留着。

03

点「启动游戏」

启动前将自动自检 Java、依赖库与资源索引。全部通过即可直接进入游戏；若存在问题，将明确提示具体项目。

账户：当前可直接使用的是离线账户——仅需命名即可游玩单人模式与局域网。微软正版登录的完整实现（OAuth 流程 + Keychain 令牌保管 + 登录界面）均已就绪， 但需先在 Azure 注册应用并填入 clientID 后方才启用，本期暂不开放。若仅游玩单机或自建服务器，离线账户已足够。
